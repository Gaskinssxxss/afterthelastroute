# Security policy

Report vulnerabilities privately to the repository maintainer via GitHub Security Advisories once this repository is published. Do not include secrets or personal data in issues.

This lab requires Docker-level privileges for deployment. Docker socket access grants broad host control. Use a dedicated disposable Linux host for untrusted topology/configuration experiments. Management ports are not published; do not add public bindings. The lab is educational and is not hardened for hostile multi-tenant use.
